# Beauty-Blind
Questo progetto è un'applicazione web per la gestione di un negozio online.

---

## **Descrizione**
L'applicazione permette di:
- Visualizzare i prodotti disponibili.
- Aggiungere prodotti al carrello.
- Gestire ordini e utenti (funzionalità base).
- Mostrare un’interfaccia semplice e intuitiva per la navigazione.

---

## **Tecnologie utilizzate**
- **Java EE (Enterprise Edition)** per lo sviluppo del backend.
- **Servlets & JSP** per la gestione delle pagine web dinamiche.
- **JDBC** per la connessione al database.
- **MySQL** come database relazionale.
- **Eclipse IDE** come ambiente di sviluppo.
